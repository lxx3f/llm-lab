A transformer reads a sequence of token ids and produces contextual hidden states.
The model uses attention to compare each token with earlier tokens in the same sequence.
A causal mask prevents a position from reading tokens that appear later.
RMSNorm keeps the scale of hidden states stable before attention and feed forward layers.
RoPE adds position information by rotating query and key vectors according to their positions.
SwiGLU combines a gated activation with two linear projections to form the feed forward network.
A language model predicts the next token from the tokens that came before it.
During training, the input sequence and the target sequence are shifted by one position.
The cross entropy loss measures how well the model predicts every target token.
A tokenizer converts text into integer ids that can be consumed by an embedding table.
Byte pair encoding starts with byte tokens and learns frequent adjacent merges from a corpus.
The vocabulary and merge rules must be saved together so that encoding is reproducible.
Special tokens are reserved before BPE training and are never merged with ordinary text.
The end of text token separates documents in a language modeling corpus.
A validation split must contain documents that were not used to fit the tokenizer or model.
A fixed random seed makes the small experiment easier to reproduce.
The optimizer updates model parameters after gradients are computed by backpropagation.
AdamW uses adaptive moments and decoupled weight decay.
Gradient clipping limits unusually large updates and can improve training stability.
A warmup schedule increases the learning rate gradually at the beginning of training.
A checkpoint stores model weights, optimizer state, configuration, and the current step.
Loading a checkpoint should reproduce the next training state rather than only the model output.
Experiment metadata records the data version, tokenizer hash, code version, and hardware.
A benchmark must distinguish a smoke test from a result that supports a scientific claim.
Latency measurements should synchronize CUDA before reading the wall clock.
The benchmark should report batch size, sequence length, warmup steps, and measured steps.
A dense feed forward layer evaluates the same parameters for every token.
A mixture of experts contains several feed forward experts and a router.
Top one routing sends each token to the expert with the largest router probability.
Capacity limits how many tokens an expert can process in one forward pass.
Dropped tokens keep their residual input when the expert capacity is full.
The auxiliary load balancing loss encourages the router to use experts more evenly.
Total parameters and active parameters are different quantities for a sparse model.
A fair comparison fixes the training token budget and records both parameter counts.
The prefill stage processes a prompt while decode generates one token at a time.
A key value cache avoids recomputing attention states during incremental decoding.
Full forward and incremental decoding should produce matching logits when cache semantics agree.
Grouped query attention shares key and value heads while keeping multiple query heads.
Latent attention compresses key and value information to reduce cache memory.
Every architecture change needs a correctness test before a performance benchmark.
Tool calling asks a model to select a function and produce arguments that satisfy a schema.
A tool executor validates the function name, arguments, ordering, and returned result.
A successful tool call does not necessarily mean that the final answer solved the task.
Evaluation should separate parsing, tool selection, argument accuracy, execution, grounding, and answer quality.
Failure analysis helps identify whether a model chose the wrong tool or lost a conversation constraint.
Structured results should include an experiment id, model version, dataset version, and timestamp.
A reproducible experiment is more valuable than an impressive number without a measurement protocol.
